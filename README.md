# Sunrise Industries

> ISO 9001:2015 Certified Manufacturer & Exporter of Stainless Steel Nipples, Couplings, Flanges, and Precision CNC Turned Components.

Ahmedabad Works, Gujarat, India.

---

## Tech Stack
- **Framework**: React 18 with Vite
- **Routing**: React Router v6
- **Styling**: Vanilla CSS (Tailored Design System with Responsive Layouts)
- **Deployment**: Production-ready static build (`npm run build`)

---

## Getting Started

### 1. Install Dependencies
```bash
npm run install
# or
cd frontend && npm install
```

### 2. Start Development Server
```bash
npm run dev
# or
cd frontend && npm run dev
```

The application will start on `http://localhost:5173/`

### 3. Build for Production
```bash
npm run build
# or
cd frontend && npm run build
```
Build output is saved to `frontend/dist/`.

- **Homepage**: Complete SS nipple engineering range, specs, CAD matrices, and direct RFQ dispatch form.
